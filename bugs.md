## B7 — `modifier` writes to GN menu/enum inputs are silently dropped, and the readback confirms the failed write

**Defect, not friction.** The `modifier` verb (`op=add_asset` / `op=modify`, `inputs={…}`
and the `collection=` param) is *supposed* to set any Geometry-Nodes input. It works for
Int / Float / Bool / Vector sockets but **silently no-ops on menu/enum sockets** — the
value is echoed back as applied but never reaches the live modifier.

**Repro (donut dogfood, 2026-07-10, native *Scatter on Surface* asset):** `add_asset` with
`collection=Sprinkles` returned `set: {'Instance Type': 'Collection', …}` and the input
dump read back `Instance Type (menu: Object|Collection = Collection)` and `Density Method
(menu: … = Density)` — but Blender kept evaluating `Instance Type = Object` (empty source →
**0 instances scattered**) and `Density Method = Amount`. The scatter produced nothing; a
human flipping Instance Type→Collection in the N-panel fixed it instantly.

**Two bugs, one symptom:**
1. **The write is dropped.** Menu sockets carry an int index / string identifier; the
   current path sets a representation Blender ignores (and/or skips the depsgraph update),
   so the enum keeps its old value.
2. **The readback launders it.** The echo and input dump are generated from the value the
   tool *tried to write*, not the modifier's effective state — so a verification read
   **confirms a write that didn't happen**. An agent has no way to detect the failure from
   any server read; it cost ~a dozen calls (probe duplicate→apply cycles, a full
   remove + re-add) chasing a phantom binding the tool insisted was already set. The
   `emits: N instance(s)` heuristic is decoupled the same way (reported 0 then 1000 — the
   `Amount` default — while a same-Density probe realized 260).

**Fix:** write menu/enum GN inputs through the representation that latches + force a
depsgraph re-eval; make the readback (`op=list` / input dump) report the modifier's
*effective* evaluated state so a failed set is visible; and report a true depsgraph
instance count instead of a pre-eval guess. Add a regression test that sets a menu socket
and asserts the evaluated result changes (headless: scatter a collection, assert realized
instance count > 0).
