This is the classic donut tutorial.

1. Add a plane, for a table. No legs needed. 
1.1. Add a marble texture PBR from Poliigon. 
2. Create a plate:
2.1. Add a very thin cylinder
2.2. Inset the middle, and drop it down
2.3. Bevel the inner rim with a high edge count to create a curve
2.4. Add a solidify modifier
2.5. Change the material to the ceramic material PBR from Poliigon. 
3. Create a donut: 
3.1. Add a torus on top of the plate. Shade Smooth. Donut proportions. Make sure it fits on the plate. 
4. Create the icing:
4.1. Select the top half of the donut, and duplicate it. Separate it out to a new object. 
4.2. Use ALT+S to puff out the icing a bit
4.3. Use the sculpt tool to grab with a small brush the edges of the icing, and pull them down a couple millimeters across the edges of the icing
4.4. Create 3 "drips" by using the grab tool with a narrow brush, and pull down three sections of icing into an icicle shape. The feel should read as "uneven".
4.5. Use the sculpt inflate brush to inflate the bulb of the icing drip in each icicle.
4.6. Apply the icing PBR texture from Poliigon.
5. Create the sprinkles:
5.1. Create a collection of sprinkles
5.2. Each sprinkle is a cylinder of 6 sides. Shade smooth. 
5.3. Create sprinkles that are different lengths, and shapes, such as slight curves and kinks. 
5.4. Make them different colors.
5.5. Add your 4 or 5 sprinkle designs to the sprinkles collection. 
5.6. Add a "Scatter on Surface" modifier to the icing, and point it at the sprinkles collection.
5.7. Increase the sprinkles density to about 500.
5.8. Add a 4x4 lattice to the top of the donut. 
5.9. Adjust the lattice to deform the icing and sprinkles. 
6. Create a coffee mug:
6.1. Add an appropriately sized cylinder, with roughly 20 sides. 
6.2. Remove the top face. 
6.3. Add two loop cuts, one at the top, one at the bottom. 
6.4. Inset the very bottom of the outer mug just a bit. 
6.5. Add a solidify modifier.
6.6. Select two faces on the bottom side of the mug, and two faces on the top side of the mug, that will be used as anchors for the mug handle.
6.7. Delete those faces. Select the edge loops and "Bridge Edge Loop Gaps". 
6.8. Apply a pottery PBR from Poliigon. 
7. Render.
