1. Start with a cube
2. Flatted the cube into a square, but hand thickness
3. Add three loopcuts, equally spaced, both along the x axis, and y axis, so the flattened cube is 4x4. 
4. Select the 4 faces that will become the fingers, all at once.
4.1. Press I twice, so the inset works on each individual square.
4.2. Bring the inset in "a little bit".
4.3. Use S-Y to even out all the selected inset faces so the sides of the inset squares are the same length.
